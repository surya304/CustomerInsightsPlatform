# CustomerInsightsPlatform
 

https://customer-insights-platform.vercel.app/

Project Overview:
I created a Voice of Customer (VoC) analytics dashboard that aggregates and analyzes customer feedback from multiple channels:
- Product Reviews
- Customer Surveys
- Social Media Mentions
- Customer Support Tickets

Key Features:
-  sentiment analysis visualization
- Category-based feedback analysis
- Multi-channel data integration
- Interactive data filtering and sorting
- Responsive design with dark/light mode support

Technical Stack:

Frontend:
- React with TypeScript
- Vite for build tooling
- TailwindCSS with shadcn/ui components
- Chart.js for data visualization
- React Router for navigation
- GraphQL client (graphql-request)

Backend:
- Node.js with Express
- GraphQL API with express-graphql
- MongoDB with Mongoose
- Environment configuration with dotenv

Infrastructure:
- Vercel for deployment
- MongoDB Atlas for database hosting
- Git for version control
